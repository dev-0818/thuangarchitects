Review date: 2026-09-03

## Ownership and measurement

- [ ] Verify Google Search Console domain ownership.
- [ ] Submit `https://www.thuangarchitect.com/sitemap.xml`.
- [ ] Monitor indexing, queries, CTR, position, and Core Web Vitals.
- [ ] Add approved analytics only after receiving a real measurement ID and consent requirements.
- [ ] Create a referral report for `utm_source=chatgpt.com`; zero referrals do not prove AI invisibility.

## Entity consistency

- [ ] Confirm `Thuang Architect` naming across official profiles and publications.
- [ ] Verify the current Instagram URL is official before retaining `sameAs` long-term.
- [ ] Add verified LinkedIn/company/directory URLs to `sameAs` only after ownership confirmation.
- [ ] Claim/verify Google Business Profile if applicable; use verified category, service area, contact data, and photos.
- [ ] Review reputable architecture directories and local/design publications.
- [ ] Seek legitimate project features, interviews, supplier/contractor citations, and earned links.

## Production infrastructure

- [ ] Confirm HTTP/apex alternatives redirect once to HTTPS `www`.
- [ ] Confirm no CDN/WAF rule blocks Google, Bing, or `OAI-SearchBot`.
- [ ] Decide GPTBot training-crawl policy independently from `OAI-SearchBot` search access.
- [ ] Verify representative URLs, sitemap, robots, metadata, schema, images, and SPA navigation after deployment.
- [ ] Validate schema with Schema.org Validator and Google Rich Results Test where relevant.

No external profile, backlink, analytics ID, or crawler policy should be created or changed without owner authorization.
